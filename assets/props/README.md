# Исходники киноатрибутики

Векторные оригиналы предметов из физического коллажа на главной.
В `public/props/` лежат растеризованные из них PNG с прозрачностью — именно
они подставляются в коллаж.

Чтобы заменить предмет: положите свой PNG с прозрачным фоном
в `public/props/` и пропишите его в `src/content/props.ts` — имя файла,
подпись, ширину, соотношение сторон и форму тела (`circle` для круглых
предметов, они катаются, `box` для остальных).

Размер PNG стоит держать около полутора ширин отображения: предметы
показываются не крупнее 190 px, поэтому файлы шире ~600 px — лишний вес.
